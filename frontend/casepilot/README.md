# CasePilot Frontend

Angular frontend for bank dispute operations.

```powershell
npm ci
npm start
```

Open http://localhost:4200. The API gateway must be available at http://localhost:8080.

```powershell
npm run build -- --configuration production
```

Production assets are written to `dist/casepilot/browser`. The CasePilot logo is stored locally in `src/assets/casepilot-mark.svg`.
